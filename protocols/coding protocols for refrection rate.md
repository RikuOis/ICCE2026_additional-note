# Coding Protocol for Reflection Rate Analysis

## 1. Overview and Purpose

This protocol defines the coding criteria, decision rules, and evaluation workflow for analyzing the validity of LLM-based agent assessments and measuring the learner's **Reflection Rate** during problem-posing revision tasks.

---

## 2. Operational Definitions of Assessment Variables

The variables evaluated in this protocol are operationally defined as follows (see also Table 3):

| Variable | Operational Definition | Coding Criterion |
| :--- | :--- | :--- |
| **Identified Issues** | Deficiencies in quiz statements, choices, or explanations identified by the Assessment Agent. | Any specific issue explicitly pointed out by the Assessment Agent as a format or content deficiency. |
| **Incorrect Assessments** | Deficiencies identified by the agent that were inappropriate, incorrect, or did not require correction. | Identified issues containing factual errors, pedagogical misinterpretations, or trivial formatting remarks that do not disrupt quiz layout or comprehension. |
| **Correct Assessments** | Deficiencies identified by the agent that were appropriate, valid, and required correction. | Identified issues pointing out clear typographical, omission, redundancy, or terminology inconsistencies that disrupt the quiz layout or content clarity. |
| **Corrections** | Valid deficiencies that were successfully revised by the student. | Correct assessments where the student's revisions directly and accurately addressed the agent's feedback guidelines. |
| **Reflection Rate** | The proportion of valid agent feedback items that were successfully corrected by the student. | Calculated using the formula:$$\text{Reflection Rate (\%)} = \left( \frac{\text{Corrections}}{\text{Correct Assessments}} \right) \times 100$$ |

---

## 3. Two-Stage Coding Procedure

Each identified issue generated by the agent is evaluated through a sequential two-stage process:

```
[Agent Feedback Item]
         │
         ▼
┌─────────────────────────────────┐
│ Stage 1: Assessment Validity    │
│ Is the feedback valid & needed? │
└────────────────┬────────────────┘
                 │
        ┌────────┴────────┐
        ▼                 ▼
  [Valid / Correct]   [Invalid / Incorrect] ──► Judgment: "Incorrect Assessment"
        │                                       (Excluded from Reflection Rate denominator)
        ▼
┌─────────────────────────────────┐
│ Stage 2: Learner Reflection     │
│ Did the learner resolve it?     │
└────────────────┬────────────────┘
                 │
        ┌────────┴────────┐
        ▼                 ▼
   [Reflected]     [Not Reflected]
        │                 │
        ▼                 ▼
   Judgment:         Judgment:
   "Correct Assessment & Reflected"   "Correct Assessment & Not Reflected"
   (Counted as Correction)            (Counted as Correct Assessment only)
```

### Stage 1: Assessment Validity Coding
- **Correct Assessment**: The agent correctly identified an actual defect (e.g., spelling error, missing punctuation, confusing wording, or terminology inconsistency) that degraded the quality of the quiz.
- **Incorrect Assessment**: The agent falsely flagged a correct expression as an error, suggested an inappropriate deletion/addition that would alter the intended pedagogical meaning, or produced a hallucinated critique.

### Stage 2: Learner Reflection Coding (Applicable to Correct Assessments only)
- **Reflected (Correction)**: The student modified the target text in direct alignment with the agent's feedback, successfully resolving the identified defect.
- **Not Reflected**: The student either made no changes, ignored the advice, or made revisions that failed to resolve the flagged issue.

---

## 4. Primary Judgment Categories

Every feedback item is assigned exactly one of the following three final judgments:

1. **`Correct Assessment & Reflected`**: The agent correctly identified an issue, and the student successfully revised the text according to the recommendation.
2. **`Correct Assessment & Not Reflected`**: The agent correctly identified an issue, but the student did not modify the text or the revision did not resolve the issue.
3. **`Incorrect Assessment`**: The agent's feedback was erroneous, unnecessary, or harmful to the quiz structure; the learner is not expected to implement this feedback.

---

## 5. Assessment Error Categories

Issues are classified into specific error categories as defined in Table 1:

- **Typographical Errors**: Spelling mistakes, miskeyed letters, or incorrect kana/kanji usage.
- **Omission Errors**: Missing required punctuation, incomplete phrases, or omitted required variables/units.
- **Redundant Errors**: Superfluous words, duplicated phrases, or extraneous symbols.
- **Terminology Consistency**: Inconsistent naming of variables, mixed notations, or varying technical terms within the same quiz.
- **Clarity of Quiz Statement**: Ambiguous question framing, confusing conditions, or unclear phrasing in the problem statement.
- **Clarity of Explanation**: Insufficient reasoning, unclear explanations of answer choices, or confusing solution steps.
